# S2 证据归档 v1

这里是 S2 已批准来源的实际响应字节，抓取 UTC 时间、URL 和 SHA-256 见 manifest.json。
packages.json 中 snapshot_sha256 对应原始 HTML/PDF 字节，不是摘要哈希。运行时每次读取核验哈希及来源元数据。

- P1：国务院意见的生态环境部正式转载；与政府原文是同一政策，不计为独立双源。
- N1：央视报道全文网页；报道/专家解释不作为政策条文。
- C1：中微2026半年报 PDF，核验第10—11页业务披露。
- H1：512480 2026一季报 PDF，核验第10页前十大指数投资，保留原净值百分比。
- R1：上交所2026规则发布网页；完整规则附件、适用条款及客户费用仍须由执行器另行核验。

这些是历史证据包，未宣称最新持仓、当前政策全覆盖或已证实受益。BK0917没有公司成分关联；688012/512480分别独立归档。未知标的不自动映射。增加/修订证据必须创建新版本ID，不能覆盖v1。

研究模型只接收人工核验摘要和来源定位，不声称读完PDF。新推断必须显式标记及引用；supported事实只允许复用已核验文本、评估和引用集合。引用结构通过不等于语义人工复核。

## 集成

主服务lifespan显式调用 `await backend.routers.policy_research.start_runtime()`，退出调用 `stop_runtime()`，并挂载 `router`。当前SQLite恢复要求单后端worker；不能多worker分别恢复别人的进行中任务。导入模块不初始化数据库。

预算预留按现有模型最高峰值价格、UTF-8字节输入上界+schema/system/封装余量、2048最大输出和18次最大重试估算；依赖LLM/SDK重试配置变更时必须同步审计。成功结果的estimated_cost_cny是保守预留上限，不是实耗或账单。预留写入任务后才可调用模型。失败不自动提交新任务。

测试使用mock模型，未发生本轮真实模型付费调用。
