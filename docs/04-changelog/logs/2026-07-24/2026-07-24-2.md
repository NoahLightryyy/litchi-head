# PD-001/002/003 动态指标体系基建 — IndicatorRegistry + 产业链位置 + 选择器

> 基于 2026-07-24 实锤 API 验证的东方财富 496 个行业分类数据构建。

## 完成内容

### 背景：实锤 API 验证（非拍脑袋）

在编码前，实际调通了东方财富 API 确认数据：

```
ak.stock_board_industry_name_em() → 496 个行业板块 ✅
ak.stock_individual_info_em('000001') → f127(行业)="银行Ⅱ" ✅
```

从而确定：API 返回**二级行业名**，需要归一化到一级（31 个，与申万一级对齐）。

### 新文件（4 个）

1. **`src/data/indicators/__init__.py`** — 包导出
2. **`src/data/indicators/registry.py`** — 核心注册表（368 行）：
   - `IndustryChainPosition` 枚举（upstream/midstream/downstream/financial/other）
   - `IndicatorDef` Pydantic 模型（含 id/name/description/field/unit/normal_range_hint 等）
   - `INDICATOR_DEFS` — 18 个指标定义的完整列表（每个含中文描述和正常区间）
   - `INDICATOR_DEFS_MAP` — id → IndicatorDef 快速查找
   - `_INDUSTRY_NORMALIZE` — **455 条行业名称归一化映射**（覆盖全部 496 个子板块→31 个一级行业）
   - `REGISTRY` — 31 个一级行业 × 每个 5-8 个关键指标
   - `INDUSTRY_CHAIN_MAP` — 31 个行业的产业链位置映射
   - `normalize_industry()` / `classify_chain_position()` 核心函数
3. **`src/data/indicators/selector.py`** — `DynamicIndicatorSelector` + `SelectorResult`
   - `for_stock(code)` 全链路：stock → get_stock_industry → normalize → classify → REGISTRY lookup
4. **`tests/test_data/test_indicators.py`** — 34 个测试

### 关键设计

```
股票代码 ("000001")
  → source.get_stock_industry("000001")          ← ak.stock_individual_info_em
     → "银行Ⅱ"                                      ← 实锤 API 返回值
  → normalize_industry("银行Ⅱ")                     ← 455 条映射表查找
     → "银行"
  → classify_chain_position("银行")                 ← 31 行业位置分类
     → IndustryChainPosition.FINANCIAL
  → REGISTRY["银行"]                                ← 8 个核心指标
     → ["pe", "pb", "roe", "eps", "debt_ratio", "roa", "net_profit_growth", "operating_cf_per_share"]
     → 展开为完整 IndicatorDef 定义
```

### 银行不显示毛利率/存货周转率 ✅（注册表每行业只配 5-8 个相关指标）
