# PD-005 三维分析上下文注入 — AI 分析师生效行业上下文

> 将行业归属 + 产业链位置 + 关键指标注入 AI 分析师/大师 prompt 的全链路。

## 完成内容

### 修改文件（3 个）

| 文件 | 修改 |
|:-----|:------|
| `src/data/collector.py` | `format_market_brief()` 新增 3 个参数（industry/chain_position/key_indicators），新增「行业分析层」分区输出 |
| `src/debate/orchestrator.py` | `collect_data_node()` 调用 `get_dynamic_indicators()` 获取行业数据，传递给 `format_market_brief()`，同时在 `market_data` 顶层保留 industry/chain_position |
| `src/data/models.py` | `MarketBrief` 文档字符串从 4 维度更新为 5 维度 |

### 测试文件（2 个）

| 文件 | 新增 |
|:-----|:------|
| `tests/test_data/test_data_collector.py` | +3 测试：行业数据完整输出 / 无产业链位置 / 无行业数据占位 |
| `tests/test_debate/test_orchestrator.py` | +1 测试：collect_data_node 含行业数据 / mock_collector 补 get_dynamic_indicators |

### 核心设计

```
collect_data_node(state, collector)
  └── collector.get_dynamic_indicators(code)     ← PD-005 新增
      ├── industry: "银行"
      ├── chain_position: "financial"  
      └── indicators: [{id, name, description, ...}, ...]
  └── format_market_brief(..., 3 个新参数)
      └── ----- 行业分析层 -----                  ← prompt 中的新分区
          所属行业: 银行
          产业链位置: 金融行业
          关键指标:
            • 市盈率: 股价/每股收益（正常范围 10-20倍）
            ...
```

### 效果

- **AI 分析师**在 `_run_analyst()` 中通过 `market_data["brief"]` 自动拿到行业上下文
- **7 位大师**在 `_run_single_master()` 中通过 `market_data["brief"]` 自动拿到行业上下文
- **交叉审阅**和**独立评审**同理 — 零额外改动
- 所有 prompt 路径现在都包含「行业分析层」，大师知道在看什么行业的股票
