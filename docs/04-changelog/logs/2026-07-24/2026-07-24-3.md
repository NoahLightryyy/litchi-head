### 核心设计

```
用户打开个股页 → "财务分析" Tab
  → useIndicators(code) → /api/stocks/{code}/indicators
    → DataCollector.get_dynamic_indicators()
      → DynamicIndicatorSelector.for_stock()
        → get_stock_industry → normalize → REGISTRY lookup
  → 返回: { industry, chain_position, indicator_ids, indicators }

FinancialPanel:
  ├─ 行业标签 ("银行 · 金融行业 · 动态筛选 8 个关键指标")
  ├─ 估值概览（四宫格，不变）
  ├─ FinancialMetricsDetail:
  │   └─ 只有 relevantIds 中的指标才显示
  │   └─ 整个section如果没有一个指标相关就隐藏
  └─ 历史对比（不变）
```

### 效果

- **银行股**（平安银行）：显示 PE/PB/ROE/EPS/负债率等 8 个，隐藏毛利率/存货周转率等 ❌
- **消费股**（茅台）：显示毛利率/净利率/营收增长率等 7 个 ✅
- **无行业数据时**：全量显示所有 17 个指标（向后兼容）
