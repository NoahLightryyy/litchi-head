### 产品决策与调研

- 用户允许历史接口回填，并确认采用“影子回填 + 正式层失败关闭”；
- 实网验证腾讯可返回 2026-07-28～31 四个完整日，每日常规时段242点；
- 新浪相同日期缺少 `09:30/13:00/14:58/14:59` 等分钟，累计量偏差最高约
  1.26%；东方财富五日接口当前断连，因此不设置经验百分比容差；

- 新增 `src/data/intraday_history.py`：

  - 242个常规分钟、正成交量、单调累计值、双源身份门禁；
  - 市场/证券/日期分区的内容寻址 Parquet + SQLite 哈希清单；
  - 最近20个正式完整日的同分钟累计量中位数；
  - 成员缺失、篡改、解码失败和行数不符均失败关闭。
- 新增 `src/data/providers/intraday_history.py`：腾讯五日影子回填，官方交易日历
  覆盖，过滤盘后扩展行，成交量从手转股，当日未完成数据不入库；
- `src/data/intraday_runtime.py` 与分时 API 接入协调器：每日回填一次影子历史，
  双源完整日自动进入正式层；影子尚未晋升时返回
  `relative_volume_backfill_shadow_only`；
- 新增8项历史契约并扩展后端接口契约；同步 ADR、模块规格、债务、交接、路线图、
  Backend README 与学习卡片44。
