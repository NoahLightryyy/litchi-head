# AI 工作日志 — 2026-08-26 证据不完整仍推理

## 用户决策

用户将原“证据不完整即零 LLM”规则简化为：证据不完整时仍提供推理，但必须做好标注。
本轮按保守边界实施：普通缺源、陈旧、采集失败或不支持允许研究推理；冲突、身份错乱、
未来数据或非法 payload 仍阻断；带限制结果不进入风控、交易员或 PM 自动执行链。

## 实现

- 新增 `EvidenceLimitation`，保存能力、缺失上游、缺失独立来源数量、来源状态和采集时间；
- 新闻/实时报价信封不完整时继续分析师和大师链，市场简报显式注入限制；
- 最终 `DebateResult`、摘要和记忆快照同步保存限制，不依赖日志才能发现；
- LangGraph 在研究推理完成后隔离受限结果，不进入风险官、交易员和 PM；
- `CONFLICTED` 及报价身份、数量、错时、未来时间等损坏错误保持首个 LLM 前阻断。
