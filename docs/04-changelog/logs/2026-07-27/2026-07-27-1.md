## 实现细节

### DP-007 裁剪策略

```
analyst_round_node 执行后
  └─ market_data 裁剪:
      以前: { brief, industry, chain_position, quote, quotes[], klines[], news[], financials[] }
      以后: { brief, industry, chain_position }
      原因: 下游所有节点（master_round / review_round / review_report / aggregate）
            只消费 market_data["brief"]，原始数据数组不再被任何后续节点读取
```

**`_trim_market_data()`** — 白名单函数，只保留 `brief` / `industry` / `chain_position`，移除所有原始数据数组（`quotes`、`klines`、`news`、`financials`）。

### 安全性分析

通过 grep 验证下游 5 个节点对 `market_data` 的全部访问模式：
- `_run_single_analyst`: 仅 `brief = market_data.get("brief", "")`
- `_run_single_master`: 仅 `brief = market_data.get("brief", "")`
- `_run_review_for_master`: 仅 `brief = market_data.get("brief", "")`
- `_run_independent_review`: 仅 `brief = market_data.get("brief", "")`
- `aggregate_node`: 完全不使用 market_data

**结论**：裁剪零风险，`brief`/`industry`/`chain_position` 已包含后续节点所需的全部信息。
