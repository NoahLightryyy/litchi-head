# 政策—标的—本金执行闭环实施计划

版本：2026-10-18 v1。用户已批准本计划方向及并行任务；本轮已推进S2证据及S3首批契约。状态以本文任务表为准，设计提案不等于冻结接口或功能上线。

## 目标与首批范围

在板块、股票、ETF详情页回答：政策为何相关、兑现证据是什么、给定本金与约束是否可执行。路径为政策原文→业务暴露→兑现与反证→确定性计算→同页对照。首批板块BK0917；公司与ETF需用业务、指数和持仓证据选定后登记，不把现有688012或159915演示页面自动当作已证明相关的首批标的。

明确不包含自动下单、全行业覆盖、公开收益排行榜。央视报道是线索，原文政策与公司披露支撑事实；转载不是独立验证。图谱草图、静态政策样例、本金假设计算继续标明边界，不能作为首批闭环验收通过的依据。

## 并行执行安排

用户授权允许多个窗口。本轮实际启动3个只读子任务：数据盘点、AI与运行链路盘点、本金与前端盘点；由主窗口唯一写入文档。只读共享当前目录符合[并行规则](../../01-guides/workflow/CONCURRENT-DEVELOPMENT.md)。未新建多个共享目录的可写窗口。

后续写代码必须一任务一worktree、一codex/分支，开始前记录起始提交、拥有路径、测试与交付提交：

| 工作流 | 路径所有权（拟定，建窗前核对） | 可并行条件 |
|---|---|---|
| 政策证据 | 新政策数据适配器/解析器及对应测试；不改共享API契约 | S1完成后，依据已批准来源范围 |
| 公司/ETF证据 | 公司与ETF证据适配器及测试；共享类型由API负责人统一编辑 | 与政策证据互不重叠 |
| API/运行任务 | 新契约、接口、持久化、去重 | S2后冻结，其他窗口只消费提交 |
| 本金计算 | 风险/数量费用纯计算模块及测试 | 执行契约冻结后 |
| AI政策研究 | 新研究编排与评测样本 | 政策契约冻结后 |
| 前端 | 详情研究组件、消费者及浏览器验收 | 上游冻结后 |
| QA/集成 | 跨端测试、文档状态、主集成；解决冲突 | 逐个接收原子提交 |

当前工作树有多轮未提交内容，不能直接假定HEAD含全部已验收功能。建立可写worktree前先按归属整理依赖提交或明确可复现补丁；禁止git add -A、整体stash、覆盖脏改动。已有其他worktree不视为本任务可接管资产；不自动清理。

## 关键决策和边界

待证据支持后选择首批公司与ETF；新增来源超出现有官方/披露范围时单独决策。本金、风险承受、实际费率由用户输入或经核验账户规则提供，禁止悄悄使用演示默认值。字段、AI输出、错误语义由S3联合冻结；本计划不是接口冻结。持仓或政策版本变化使结果失效；价格不足或规则不明时不得给出可交易数量。

验收首先看证据与约束正确性，不用解释长度、图形数量或单次演示成功代替效果验证。发生上游缺失时返回明确研究缺口和继续核验项；不得伪造已核验关联。
