# API模型与投资效果评测协议草案

日期：2026-10-18。版本：审阅稿1。目标是判断额外工具、检索和辩论是否增加真实价值，以及增益是否值得其成本。本文是[主验证协议](../DECISION_BASELINE_AND_SHADOW_VALIDATION.md)的首轮实验配置提案，指标定义和防泄漏规则以主协议为准；完整协议新增数值仍待冻结，未启动完整实验或交易。2026-10-18用户另行授权的小样本已执行，见[独立实测报告](SMOKE_RESULT_2026-10-18.md)；不能视作本完整协议已验收。

## 首轮要回答的问题

同一模型能否因结构化证据、计算工具和反证而减少错误？多Agent相对单Agent能否在相同预算内改进判断？改善是否延续到前瞻模拟结果，而非只让报告更好看？

首轮固定仓库DEFAULT_MODEL当前值deepseek-v4-pro及非思考配置，执行时记录实际返回模型标识、API版本、采样配置和日期。提供商版本变化后另开实验。首轮只比较工作流，不声称跨模型排名。

## 实验矩阵

| 组别 | 输入与流程 | 要隔离的增量 |
|---|---|---|
| A 单次分析 | 同一冻结证据包，一次调用，输出统一结构 | 单Agent基线 |
| B 检索与计算 | 在同一证据包内检索，允许确定性计算工具 | 工具增量 |
| C 反证核验 | B之后检查关键主张、来源和反例，可修订一次 | 核验增量 |
| D 多Agent | 与C相同工具，多视角提出观点后由评审汇总 | 辩论增量 |

四组可访问的信息集合相同，禁止某组联网取得额外信息。政策事实题用策展的来源包；数值题用原始表格和独立计算答案。每次新增能力与紧邻组做配对比较，正式主比较预先指定为C对A；其他比较为探索性，不事后挑冠军。

建议每个案例每组总输出预算8,000 token、总输入计费预算60,000 token、工具调用8次、墙钟180秒；A最多1次模型调用，B/C最多3次，D最多5次。预算含评审、修订和重试；实际消耗逐项记录，不能用每Agent额度代替整组额度。统一金额上限单独限制；缓存用量、输入重传和推理计费用量若存在均纳入。

首轮调用费建议硬上限300元，仅为预算提案；运行前按实际API价格估算能完成的整批配对样本。预算不足时不运行不完整的对照批，不能只让便宜组完成再比较。不切换新模型或新凭据。

## 离线能力样本

40个独立案例：10个开发集、30个封存评测集。按事件和公司分组隔离，相同事件的改写不得跨集合。

封存集含财务计算8例、引用与时效8例、政策传导6例、缺失或冲突信息8例。每组每例独立运行3次，共360条输出；另10个开发案例的调试费用也计入预算。该规模用于流程与明显错误检验，不足以宣称投资能力已验证。公开历史材料可能进入模型训练，历史题成绩只能证明当前答题表现。

评分由确定性计算器与两名独立复核人完成；复核人不知道输出组别。政策传导按“事实忠实、证据支持、条件完整、反证明确”逐项0/1评分，保留评分说明，分歧经复核记录解决。如果只有一名评审，标为单人初评，不能对外称独立双审。LLM裁判只做预筛，不独占裁决。

## 前瞻影子验证

建议观察8个交易周，再等待最后一批20交易日标签成熟。时间长短和样本数量不能互相替代；市场状态不足时如实说明，不强行凑牛熊震荡。

- 股票池：实验开始前最近一个交易日的沪深300成分，锁定名单与来源时间。后续停牌、退市风险、不可成交也保留记录，不按事后存活股票重建样本。
- 每个交易日北京时间16:00冻结资料，从当日可获得且符合权限的池内标的按“日期和代码的固定哈希”选5只。选择规则不使用未来收益；数据缺失仍保留所选位置，记失败或拒答，不换成资料齐全者。
- 每组面对同一5只及同一数据。常规40交易日预计200个股票日案例；并非200个独立市场环境。
- 输出1/5/20交易日相对沪深300总收益口径的超额上涨概率，主预测指标是5日Brier。事件定义为相应窗口超额收益严格大于0；中性容差若要调整须开新版本。
- 预测标签采用下一交易日开盘至第h交易日收盘的总回报，股票公司行动和基准口径须一致；行情或公司行动缺失时标签待定，不能填0。停牌延迟/不可成交情况另标，预测标签与可交易收益分开。
- 决策时间戳、原始证据哈希、模型与Prompt版本、调用预算、概率、拒答、目标仓位先写入不可变快照，再计算结果。未冻结快照的输出不入正式成绩。

## 投资效果赛道

建议各组以10万元模拟本金开始，不加杠杆、不做空。单一标的上限10%，股票总暴露上限50%，每周首个交易日开盘按上一交易日已冻结的研究结果调整，其余现金不计息。以上仅评测控制参数，不是推荐的用户资产配置。

为隔离研究能力，选股映射固定：按5日概率选最多5只、概率严格高于0.5才纳入，每只目标10%；并列按代码排序。D不能自行扩大仓位。统一执行器使用当时证券交易单位、权限、费用和公司行动规则；这些规则未核验则不得开始经济排名。

主经济基线为同样50%股票暴露的冻结股票池等权组合，保留50%现金，同频再平衡；现金、沪深300匹配暴露组合、冻结20日动量规则、A组作为辅助对照。参考指数用于预测标签，不能与主经济基线混称。

成交以下一可执行时点的原始价格为基础；暂停交易或无法确认涨跌停可成交性则不成交，未成交订单当日取消，保留原因；持仓无法卖出时保留真实暴露。不得拿收盘后知道的价格在当天收盘成交。数据不足以验证执行时，经济榜标“不可评估”，不凭空假定成交。

成本表必须在开跑前填入真实券商费率、最低佣金、税费、滑点及适用品种，来源/日期附表。本文不把假设费率冒充真实费用。分别报告交易后净收益与再扣API研究费的收益；一次性开发研究费另列，不能把共同研发费重复扣到每个用户账户。

## 排名规则与空白成绩表

| 分榜 | 主排序指标 | 必须同时披露 | 当前成绩 |
|---|---|---|---|
| 证据能力 | 可回答案例的正确率降序 | 引用支持率、遗漏率、失败率 | 未运行 |
| 概率预测 | 5日Brier升序 | 1/20日表现、校准、覆盖率 | 未运行 |
| 经济效果 | 成本后相对主基线超额降序 | 最大回撤、暴露、换手、Sortino、API费 | 未运行 |
| 可靠性 | 任务完成率降序 | 超时、违规、拒答正确率 | 未运行 |
| 效率 | 每个正确完成任务的成本升序 | 正确率、覆盖率、P95延迟 | 未运行 |

Brier为平均(p-y)²。拒答不伪造概率；已回答Brier与覆盖率并列展示，并给出将拒答按最大损失1计入全案例的保守敏感性结果，防止只回答容易题。事实题空答/超时计未完成；缺证题正确拒答按预设答案计分。

同日股票和同一事件具有相关性：统计按事件/交易周分块配对重采样，报告95%区间、有效块数和样本分母，不按独立股票日抽样夸大显著性。小样本时只给探索性排序；主比较区间包含零则写“未证实差异”。多项探索性比较不得包装为唯一显著发现。短窗口不强调年化收益，分母为零或无下行波动的比率记不可评估。

违反点时隔离、不可变记录或执行门禁立即暂停实验并标记受影响版本无效；预算耗尽停止新批次；收益差不作为删除样本或提前终止的理由。技术恢复后是否另开版本由预注册规则决定，保留中断日志。
