# FW-010 前端五态与陈旧 AI 结论安全审计

> 审计日期：2026-08-26
> 范围：`frontend/app/`、`frontend/components/`、`frontend/lib/hooks/`、统一 API client，
> 以及浏览器可见的后端成功/空数据/断开/恢复行为。
> 总任务入口：[WORKLIST.md](WORKLIST.md)

## 结论

当前前端已经有全局离线横幅、后端连接状态、页面 Error Boundary，以及首页主要组件和
K 线的 loading/error/empty/data 分支；但**尚未达到 UX-1 五态验收**。

主要风险不是“没有漂亮错误页”，而是部分失败仍会渲染成正常 data 或 empty：

1. 后端市场接口在上游无数据时返回 HTTP 200 和指数 `0.00`、宏观“暂无数据”、空标题
   新闻，前端无法知道这是失败；
2. 辩论重新触发或轮询失败没有清除/冻结旧结果，旧 AI 结论可能继续显示；
3. 新闻、信任度、复盘、技术、资金和财务等次级查询把 error 合并为 empty 或静默部分
   成功，用户无法区分“确实没有数据”和“数据源失败”；
4. 后端恢复后，全局“重试”只恢复健康状态，不会让已经失败的页面查询自动恢复。

因此本次只完成了**审计与复现**，没有修改尚未确认的失败契约、用户文案或风险默认值。

## 审计方法

- 静态检查所有页面、数据组件、TanStack Query hooks 和统一 HTTP client 的状态分支；
- 启动真实 FastAPI 与 Next.js 开发服务器，验证成功/空数据界面；
- 停止本次会话启动的后端，验证断开、查询失败和全局健康提示；
- 恢复后端，验证全局重试与页面数据恢复是否联动；
- 直接读取实际 API 响应，确认界面状态来自后端事实还是占位值。

## 真实浏览器证据

### 后端可达

- 全局显示“后端已连接，诊断信息暂不可用”；
- 首页指数渲染为三个 `0.00` 正常卡片；
- 宏观简报渲染“暂无数据”；
- 热点新闻渲染出多条可点击链接，但标题、日期、来源为空；
- `/stock/000001` 的行情成功响应为空，行情区域持续显示无文字骨架；K 线、技术、资金、
  信任度和新闻显示各自空态；
- `/retro` 空数据状态正常显示 0 条记录。

实际响应片段：

```json
{"data":[{"code":"000001","price":0.0},{"code":"399001","price":0.0},{"code":"399006","price":0.0}],"meta":{"cached":true}}
```

```json
{"data":{"summary":"暂无数据"},"meta":{"cached":true}}
```

热点新闻响应含 URL，但 `title/date/source` 为空字符串，仍被前端当作 data 渲染。

### 后端断开

- 全局横幅正确显示“后端服务未连接”并提供重试；
- 首页指数、板块和宏观简报进入错误态；
- 热点快讯错误被错误地显示为“暂无实时快讯”；
- 个股与板块页面能进入页面级错误态并提供重新加载；
- 复盘页面最终显示 `0/暂无数据/暂无复盘记录`，无法看出请求失败。

### 后端恢复

- 点击全局“重试”后，健康横幅恢复为已连接；
- 同一板块页仍停留在“板块数据加载失败”，业务查询没有随健康恢复重新执行；
- 用户必须再点页面“重新加载”或整页刷新。

## 难点与决策闸门

1. **市场接口失败策略**：指数缺失应返回 503、partial payload 还是显式 unavailable 字段，
   属于 API/错误策略决策，本次不代替用户选择；
2. **用户可见文案**：RAW 冲突、来源不足、陈旧缓存、空数据和网络失败的最终文案需要
   用户确认，本次只记录现状；
3. **真实离线黑盒**：当前浏览器验收接口没有网络仿真开关，代码路径存在但未做整机
   断网验证；TD-076 自动化底座和后续人工拔网线验收继续覆盖；
4. **陈旧 AI 实网复现**：需要先产生一次成功的外部模型辩论，再让下一次失败，会产生
   模型调用和费用；本次以确定性代码路径确认风险，没有触发付费调用。
