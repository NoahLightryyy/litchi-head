# 产业链证据接入方案

日期：2026-09-07。用户已批准正式政府资料及公开披露文件接入，生产接口和前端使用经过审核的本地证据目录。

## 已开发

`src/data/chain_evidence.py`冻结独立Pydantic证据模型，附行业环节节点、公司节点及明确关系。来源记录URL、发行者、资料日期、核验日期和原文定位。节点/边引用必须存在；重复ID、非法URL、日期倒置、无证据引用、错误板块身份均拒绝。行业环节不能成为企业供货边。加载器仅读取显式本地文件，不自动发网请求、不按板块名字模糊猜关系。结构校验不能代替事实审核。

`src/data/catalogs/chain/BK1629.json`为已接入的真实资料目录。测试验证证据引用、HTTP日期序列化和消费者拒绝错误证据。

## 可审核的首批数据

来源：工信部等四部门《国家人工智能产业综合标准化体系建设指南（2024版）》，2024-07-02发布，湖南省政府全文转载：
https://hunan.gov.cn/zqt/zcsd/202407/t20240702_33344121.html
定位：“一、产业发展现状”第1段。2026-09-07核验。

| 官方资料层次 | 展示内容 |
|---|---|
| 基础层 | 算力、算法、数据 |
| 框架层 | 模型开发框架与工具 |
| 模型层 | 大模型等技术与产品 |
| 应用层 | 行业应用场景 |

该样例只支撑行业结构，不能证明288只成分股分别处于何层，更不证明任意两家公司有供需合同。因此不生成公司节点、供应商箭头、瓶颈星标或投资评级。资料年份显式展示，不称实时关系。

BK1650 通信技术采用 `src/data/catalogs/chain/BK1650.json`：工信部正式发布的《中国光电子器件产业技术发展路线图（2018—2022年）》，4 个节点与 3 条产业环节顺序。仅覆盖历史资料中的光通信子链，不推断当前企业供货。官方发布页、PDF 链接与页码均随接口提供。

## 已批准的生产来源范围

用户已批准使用政府/部委正式产业资料，以及交易所/巨潮公开的公司公告和年报。先冻结可审核证据目录，随后接入HTTP与前端；不使用付费账户，不接模型猜测关系。逐板块确定资料可支持的覆盖，不能承诺一次覆盖1000板块。

## 后续实施边界

1. 独立证据响应区分industry_activity与company，证据链接可展开查看；HTTP模型先提交，再改消费者。
2. 行业结构和企业供需分开展示，不用单一上下游箭头混合表达两者。
3. 数据损坏/缺证据不隐藏已有行情，明确图谱未覆盖原因。
4. 右侧现有行情统计摘要与AI产业链研究分开命名，移除错误的AI评级暗示需要独立明确文案与契约。
5. 用BK1629和BK1650做首批浏览器验收，其他板块逐项增加证据；源不可用和未知板块保留可见状态。

## 2026-09-07 正式接入契约

用户已批准官方文件及公开披露资料。详情 API 新增可空 `chain_evidence`，结构由 `src/data/chain_evidence.py` 冻结：来源包含发布日期、核验日期和定位；节点引用来源，边须明确关系类型。旧 `chain_map` 保留兼容。无目录返回 null，目录校验失败仅停用地图，行情继续返回并附限制。AI 目录移入 `src/data/catalogs/chain/BK1629.json`；前端不得把无边层次解释成企业供货关系。

消费者兼容旧服务未提供 `chain_evidence`，新服务固定返回对象或 null。展示依据使用原生 details/summary，键盘可展开；来源 URL 仅允许 http(s)。2026-09-08 已验证两个实际详情接口及页面，资料读取无需额外外网请求。

## 地图交互

紧凑编号节点与来源支持的边共同呈现；选中环节或箭头后，在单一详情面板查看说明及依据。资料年份常显，覆盖范围可展开。无边目录不添加顺序连线。节点和关系按钮支持键盘、选中态及关联详情区。
