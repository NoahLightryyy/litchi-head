# 产业链证据接入方案

日期：2026-09-07。用户已批准正式政府资料及公开披露文件接入，生产接口和前端使用经过审核的本地证据目录。

## 已开发

`src/data/chain_evidence.py`冻结独立Pydantic证据模型，附行业环节节点、公司节点及明确关系。来源记录URL、发行者、资料日期、核验日期和原文定位。节点/边引用必须存在；重复ID、非法URL、日期倒置、无证据引用、错误板块身份均拒绝。行业环节不能成为企业供货边。加载器仅读取显式本地文件，不自动发网请求、不按板块名字模糊猜关系。结构校验不能代替事实审核。

`src/data/catalogs/chain/BK1629.json`为已接入的真实资料目录。测试验证证据引用、HTTP日期序列化和消费者拒绝错误证据。

## 可审核的首批数据

来源：工信部等四部门《国家人工智能产业综合标准化体系建设指南（2024版）》，2024-07-02发布，湖南省政府全文转载：
https://hunan.gov.cn/zqt/zcsd/202407/t20240702_33344121.html
定位：“一、产业发展现状”第1段。2026-09-07核验。

| 官方资料层次 | 展示内容 |
|---|---|
| 基础层 | 算力、算法、数据 |
| 框架层 | 模型开发框架与工具 |
| 模型层 | 大模型等技术与产品 |
| 应用层 | 行业应用场景 |

## 后续实施边界

1. 独立证据响应区分industry_activity与company，证据链接可展开查看；HTTP模型先提交，再改消费者。
2. 行业结构和企业供需分开展示，不用单一上下游箭头混合表达两者。
3. 数据损坏/缺证据不隐藏已有行情，明确图谱未覆盖原因。
4. 右侧现有行情统计摘要与AI产业链研究分开命名，移除错误的AI评级暗示需要独立明确文案与契约。
5. BK1629和BK1650保留静态证据目录；其他板块可使用下方资料驱动地图入口，源不可用和未知板块保留可见状态。

## 2026-10-07 通用地图第一阶段契约

`backend/sector_maps.py` 与 `backend/routers/sector_maps.py` 定义独立的 AI 候选地图，
不改变 `ChainEvidenceMap` 静态已审核目录语义。所有 BK 代码使用同一入口，不再逐板块硬编码。

- `GET /api/market/sector/{sector_id}/map?version=N`：MapView，含 current（无记录为 null）、
  history（倒序版本/生成时间）、automatic_updates（本阶段恒 false）。GET 不调用 AI。
- `POST` 同路径：无请求体，主动采集并生成；相同资料哈希直接返回原版本。
  单进程最多2个请求、同板块互斥，每分钟4次；采集80秒、AI100秒超时。
- MapVersion 含 schema_version=1、version、sector_code、generated_at、evidence_revision、
  model、review_status=ai_unreviewed、evidence、graph。SQLite 事务追加版本，不覆盖旧版本。
- graph 包含 map_kind（industry_chain/concept_relationship/market_structure）、scope、nodes、edges。
  node=id/label/explanation/citations；edge=source/target/explanation/citations。
  citations=source_id/quote。逐字引用必须存在于已取得节选中；这不等于语义核验，全部按 AI 推断展示。
- evidence：板块身份、采集时间、成分资料读取时间、成分总数、采样代码、来源和缺口。
  复用现有东方财富目录/成分接口及新浪公司资料/披露节选；按代码取前6家公司、每份4000字，
  并非代表性样本，不宣称全产业链完整。资料无法支持的节点与连线不得补造。
  成分接口失败可读取同板块同类别的校验历史快照，日期与成员变化缺口常随资料披露。
- 错误使用 error.code/message/retryable：404 MAP_BOARD_NOT_FOUND（不重试）；429 MAP_BUSY；
  503 MAP_READ_FAILED/MAP_EVIDENCE_UNAVAILABLE；504 MAP_TIMEOUT；502 MAP_FAILED。
  其余均可手动重试，失败不删除已有图，前端无自动付费重试。

验收：BK1325及任意未配置目录的板块能请求生成、查看引用、重新进入恢复记录、选择历史版；
断网和模型无效引用必须可见，且上次结果仍存在。重大事件自动监控、候选审核激活、
图差异与历史研究关联在后续阶段实现；本阶段界面必须明确“自动更新尚未启用”。

前端 `GeneratedMap` 在正常详情与行情失败页均可用；行情接口失败不会阻断资料图。
已审核静态图仍保留，生成图单独展示为待复核，旧空态文案改为引导使用资料地图。
2026-10-07 独立预览 3046/8046：BK1325 实采18份节选，真实 DeepSeek 生成9节点3条候选边；
浏览器展开引用和整页刷新恢复 v1 均验收通过。候选边只做引用字符校验，未完成语义审核。

## 2026-09-07 正式接入契约

用户已批准官方文件及公开披露资料。详情 API 新增可空 `chain_evidence`，结构由 `src/data/chain_evidence.py` 冻结：来源包含发布日期、核验日期和定位；节点引用来源，边须明确关系类型。旧 `chain_map` 保留兼容。无目录返回 null，目录校验失败仅停用地图，行情继续返回并附限制。AI 目录移入 `src/data/catalogs/chain/BK1629.json`；前端不得把无边层次解释成企业供货关系。

消费者兼容旧服务未提供 `chain_evidence`，新服务固定返回对象或 null。展示依据使用原生 details/summary，键盘可展开；来源 URL 仅允许 http(s)。2026-09-08 已验证两个实际详情接口及页面，资料读取无需额外外网请求。

## 2026-10-18 缺图时自动生成研究草图

用户明确要求“没有就绘制”。原先只有chain-analysis：目录缺失直接404，模型不会参与。新增独立chain-draft接口，契约见[AI草图契约](../../../06-departments/08-backend-api/CHAIN-DRAFT-CONTRACT.md)，先提交8f92a50冻结后接前端。此模式允许基于一般知识的节点和关系推断，但不称为核验资料，不生成公司供货关系或引文。

东方财富ChainExplorer有证据时维持既有图，无证据时按代码/名称自动请求草图；新浪板块也有同一组件。图用虚线、有向连线、AI推断标签，每个节点包含作用和核验事项；概念分类可绘制概念结构。POST返回前执行结构校验和原子持久化到data/chain_drafts；再次打开读取缓存。前端查询按代码/名称隔离，仅对暂时错误有限次自动恢复，离线和生成错误可见，用户可手动重试。模型版本或提示版本变更隔离缓存；没有定期付费刷新。

浏览器实测BK0917半导体概念生成7节点7边，非硬编码数据。持久化保存模型请求名和时间，不宣称取得实时原文或锁定提供商模型修订。现阶段草图未做自动事实核验，正式关系仍需来源层补证。

2026-10-18恢复逻辑修正：首次缺图自动请求；失败后返回页面或恢复联网重新获取，成功结果保持新鲜且不重复生成。繁忙最多6次自动重试，网络/429最多2次，模型失败/超时最多1次；间隔5至15秒。参数、缓存存储及消费者结构错误不在当前页面自动重试。次数耗尽显示错误与手动重试，不永久锁死失败缓存。
