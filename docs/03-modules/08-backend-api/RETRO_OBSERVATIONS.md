# 复盘自动市场观察（2026-10-27）

GET /api/retro/observations?record_ids=retro_x,retro_y，1至10个唯一记录ID，每个只允许字母数字下划线和连字符，非法请求422。
返回RetroObservationsResponse，结构事实源backend/retro_observation_contract.py；不修改旧记录、手动结果、成交或统计准确率。
查不到记录逐项not_found；源失败unavailable，单条失败不吞掉其余。无后续交易日waiting，至少两根可比收盘observed。

旧记录的当时价格普遍为空，因此统一使用“记录日期起首个可取得交易日收盘 → 最新已结束交易日收盘”作为观察区间，明确返回起止日期/价格。
有时区的创建时间转北京时间日期；旧无时区记录保持记录日期，不能冒充精确研究时刻。基准若晚于记录日期需说明。
沿用已有腾讯RAW日线与950自然日窗口，不与复权序列混用。输出是未复权收盘价变化，除权/分红可能影响比较，不是总回报或账户盈亏。
看涨与正变化、看跌与负变化为same，反向opposite，零变化flat；中性或未知方向no_direction。
没有新增盈利阈值、交易期限或风险默认值；这是当前观察，不把不断变化的行情认定为最终研究正确率。

前端按10条一页自动读取，页面打开每分钟复查；服务5分钟同股缓存并限制并发，读取不触发AI、不调用订单。
原始研究、人工标记保留在详情。股票名称代码链接/stock/{code}，点击链接不触发行展开。
