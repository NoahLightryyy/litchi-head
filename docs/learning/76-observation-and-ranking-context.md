# 76｜让系统自动解释结果，先把比较起点说清楚

一句话：自动取得行情并解释变化，不等于能把一段涨跌直接写成账户收益或最终判断正确。

## 项目真实代码

- `backend/retro_observations.py`：旧记录缺当时价格，用明确日期的首个已取得收盘建立可见参考区间；不修改历史判断。
- `frontend/components/retro/retro-board.tsx`：每页10条，自动读取，有价格变化就显示，尚无第二个收盘则解释等待原因。
- `frontend/lib/sector-summary.ts`：只统计同来源当前范围；三个靠前板块可能重复持股，因此不能把流入金额加起来叫全市场资金。
- `frontend/components/macro/sector-summary.tsx`：先说看到什么、可能意味着什么，再把近期新闻和经济传导路径放进可展开解释。

## 自己试试（5分钟）

1. 跑retro-observations测试，把原记录价格设为空，检查仍有清楚的基准日期。
2. 把第二天收盘改成与起点相同，确认显示“暂未变化”，不是盈利或正确。
3. 给榜单混入另一个来源，确认不参与当前来源统计。
4. 把背景新闻日期设到未来，确认不把它用作当前背景。
