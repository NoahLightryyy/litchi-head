# 63｜新闻热点：词频不是市场方向

一句话：先确定新闻样本、时间和计数单位，再把主题频次可视化；热度不能直接变成利好利空。

## 项目真实代码

`frontend/lib/news-topics.ts`：清洗标题和链接，合并相同标题，按文章而非词语重复次数统计。领域主题通过同义规则合并，重复实体通过 `Intl.Segmenter` 提取；泛词、数字和短通用词不进入候选。

`frontend/components/macro/news-topics.tsx`：字号呈现相对热度，数字给出准确文章数，点击后展示参与统计的原文。关注点可以重叠，不画占比饼图。所有文本作为 React 文本节点渲染，不插入新闻 HTML。

时间分两种：样本读取时间、新闻发布时间。未知发布时间不能用读取时间代替。近 24 小时只过滤当前已取得的文章，不代表已采集完整 24 小时新闻。无时区字符串不按法国本地时间猜测。

“AI 投资风险”和“AI 技术进展”都能增加人工智能热度，但方向不同。当前规则只归类主题/关注点，不能输出“建议买入 AI”；后续若做语义倾向，需要独立模型、证据和质量评估。

## 自己试试（5 分钟）

1. 在 frontend 执行 `node --experimental-strip-types --test tests/news-topics.test.mts`。
2. 将一条新闻复制三次，再在标题中重复三次 AI，观察同主题仍只计一次。
3. 把日期改为 `nan`，比较当前快讯与近 24 小时样本数。
4. 点击词云检查原文是否确实提及该主题；尝试“可能不会扩产”，理解词规则为何不能直接判断供需方向。
