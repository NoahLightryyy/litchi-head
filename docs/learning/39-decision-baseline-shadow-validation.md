# 39｜决策 Baseline 与影子验证

> **一句话**：没有预先冻结的比较线，AI 的每次胜负都只能讲故事，不能证明增量价值。

## 先分清两个“基线”

- 性能基线回答“系统快不快”；
- 决策 baseline 回答“AI 是否比简单办法更有用”。

本项目需要同时比较现金、市场指数、等权持有、简单规则和 AI 消融版本。只有市场基线，
无法证明多 Agent 的价值；只有单 Agent 对照，又无法证明系统能跑赢简单市场暴露。

## 为什么要影子运行

影子运行是在真实时间生成建议和留痕，但暂不自动下单。它保留了当时真正可见的数据，
又避免在证据不足时用真钱替系统试错。

核心顺序：

```text
预注册规则 → 同时生成 AI/基线 → 决策先落盘 → 到期自动贴标签 → 配对统计 → 复盘
```

如果先看到结果再改规则，就发生了“目标泄漏”；如果用今天的复权因子重算过去，就发生了
未来信息泄漏。

## 不只看收益

一套合格评估至少有四张成绩单：

1. 预测：准确率、Brier、校准曲线；
2. 经济：成本后超额收益、Sharpe、最大回撤；
3. 安全：拒答质量、数据冲突拦截、高置信错误；
4. 运行：耗时、费用、失败和重启恢复。

收益高但回撤失控，或准确率高但扣费后亏损，都不能算通过。

## 自己试试

选三只股票，假设今天同时记录 AI 建议和“保持现金”基线。先写下：

1. 观察 1 日还是 5 日；
2. 用哪个时刻价格；
3. 成本怎么算；
4. 涨跌多少算中性；
5. 停牌或数据缺失怎么办。

一周后严格按原规则评分，不许改题。你会立刻理解“先冻结规则”为什么比复杂公式更重要。
