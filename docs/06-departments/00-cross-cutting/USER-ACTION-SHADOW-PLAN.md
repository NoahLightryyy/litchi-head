## 已确认现状

- 旧 `/api/retro/{record_id}/action` 会覆盖字段，不是不可变行为账本。
- 旧 `actual_return_pct` 是“辩论价到观察价”的市场涨跌，缺少成交、数量、费用与
  滑点，不能表述为真实账户盈亏。
- `src/debate/mirror.py` 的 `MirrorReport` 比较大师历史观点，不是用户行为镜子；前端
  也没有用户行为镜子的完整消费闭环。
- 旧 0 分或 0 置信度记录未经核验不能成为有效 AI 样本；缺值不得补零。

## 第一批冻结契约

- `POST /api/user/action`：`X-User-Id` + `client_action_id` 提供用户逻辑隔离与幂等；
  相同事实重试回放，复用标识提交不同事实返回 409。
- `GET /api/user/actions`：只能在指定用户内查询，支持股票、会话和分页过滤。
- 事件时间必须带时区；数量、成交价均可缺失但不得补零；成交价存在时币种必须显式。
- `ai_decision_id` 只保存引用，当前统一标为 `unverified`，不得进入正式 AI 效果样本。
- 账本失败返回 503 且允许使用相同幂等键重试；写入成功后回调失败不回滚事实事件。
- 旧 `/api/retro/*` 暂留兼容并标记 deprecated；其收益字段明确为市场变化而非账户盈亏。
