1. 第一批并行盘点：DR-01数据覆盖、DR-02运行存储、DR-05验收矩阵、DR-06时效原则。API拟契约，前端拟状态布局；尚不各自发明字段。

3. API冻结契约与提交SHA；QA核对语义后，前端才能消费。生产过期阈值/新源等决策须用户批准后落地。
4. 集成分支验证断源仍读最近有效快照、重启恢复、上游恢复后原子换新、旧数据不越过门禁。保留失败证据。
5. 真实连续观测后才关闭TD-081。观测窗口与SLO数值由QA/基础设施提交可测方案确认，当前不承诺未经测量的百分比。

每次交接必须含：任务ID、负责人/执行会话、隔离分支/路径、输入版本、产物路径、提交SHA、测试证据、阻塞、下游确认。
状态按“待接单→已接单→实现中→已冻结→待集成→待实网验收→完成”流转。文档登记/消息送达均不等于接单或完成。
一个可写会话一个worktree；不得写本协调worktree、共享main或占用/重启3000/3001/8000预览服务。
跨端合流只在集成分支完成，不自行推送/合并。数据和基础设施先约定文件所有权，禁止同时修改同一实现文件。
