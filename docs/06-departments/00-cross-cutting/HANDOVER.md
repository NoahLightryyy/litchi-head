## 2026-08-26 Phase R 生产封口跨部门协调会

### 会议决议

1. **沿用现有 11 部门体系**：本轮不创建“前端部/后端部”之外的新组织，不移动代码或
   文档目录；两条大类交付线只是跨部门任务编组，不改变部门专业边界。
2. **后端可信生产链**：数据 → 辩论 → Agent → 风控 → 交易 → 记忆/回测 → 后端 API，
   共同对“证据限制可见、损坏阻断、可追溯、可恢复”负责。
3. **前端证据可见链**：后端 API → 前端 → 浏览器验收，共同对“状态不混淆、失败可见、
   不展示陈旧结论”负责。
4. **KR-3B-2 已于 2026-08-26 完成**。错误码、归并顺序和重试语义已经用户确认并
   冻结；其余部门不得绕开结果组装器或提前发明第二套契约。
5. **转段路线已确认**：用户于 2026-08-30 指示继续后端开发，现行 K 线计划进入 KR-4；
   KR-4A 适配层已完成，最小效果验证仍在 KR-3～6 完成后按冻结协议执行。
6. **多窗口开发隔离**：一个可写窗口使用一个独立 worktree + `codex/` 分支；后端冻结
   契约并原子提交后前端再接线，最终通过集成分支进入 `main`。共享脏工作树禁止
   `git add -A`，详见[并行开发规则](../../01-guides/workflow/CONCURRENT-DEVELOPMENT.md)。
