# 后端主管总工作表

> **唯一用途**：从后端主管视角统一管理数据、辩论、Agent、记忆、风控、交易、回测、
> 后端 API、基础设施和质量保障之间的上下游交付。
> 本表只做协调，不替代 KR、FD、RC、TD、ADR 或各部门 `HANDOVER.md` 的事实源。

## 使用规则

- `BW-xxx` 仅是 Backend Work 协调编号，不是新需求编号或技术债务编号。
- 跨部门后端工作的总状态只在本表更新；部门交接保留实现细节、代码位置和本部门债务。
- 前端只作为 API 契约的下游接收方出现；前端实现、文案和组件测试不归本表执行。
- 后端交付给前端前必须冻结 Pydantic/OpenAPI、错误码、状态、重试与兼容语义并形成原子
  提交；并行窗口使用独立 worktree，跨端只在集成分支合流。详见
  [并行开发规则](../../01-guides/workflow/CONCURRENT-DEVELOPMENT.md)。
- 字段、风险/资金默认值、数据源、错误处理策略和转段顺序仍遵守用户决策闸门。
- 状态：✅ 已完成；🟢 可并行；🟡 进行中；⏸️ 待决策；🔒 待上游；🧪 待验证。
