## 目标与已确认事实

用户进入 /stock/300199，应由本站获取关联信息并展示来源、真实发布时间和关联依据；仅查看原文时外跳。单源可展示但明确来源，搜索失败与查无结果必须区分。

- backend/routers/stocks.py 的 /{code}/news 仍调用 DataCollector.get_news，最多返回20条。
- akshare 路径使用 stock_news_em；adata_source.py 与 zzshare.py 的 get_news 是空实现，不能算有效新闻备用源。
- providers/news.py 已有东方财富关键词搜索及新浪快讯适配；news_runtime.py 已有 SQLite 滚动缓存。
- /api/v1/evidence/news/aggregate 属证据链；NEWS_EVIDENCE_POLICY 要求两独立上游，滚动窗口覆盖不足会标记 stale。不能仅换前端 URL 就声称完成。
- 本次法国网络实测300199两路可达：38条展示项，包括7条标题关联报道、28条摘要提及、3条官方公告；官方证券目录提供公司名称。一次成功不证明长期可用或全网覆盖。

## 搜索补充的范围

1. 优先复用已有新闻关键词检索和滚动新闻库，返回有效单源内容及明确限制。源故障不能表述成“近期没有消息”。
2. 公告单列：盘点纠正初始判断，已有CninfoDirectAnnouncementSource通用公告适配。展示层复用其身份查询及字段校验，增加异步有界分页，按secCode和orgId核验，不推测公告主题或精确发布时间。
3. 通用网页搜索作为补充渠道进入 NR-01 选型：列候选接口、法国实网可达性、授权/费用、速率及索引日期质量。选型未确认、凭据未配置前不得显示“已自动全网搜索”。新增付费或账户操作另请用户确认。
4. 搜索结果须核验主体及原文可追溯性；未取得正文的条目标为搜索结果/仅摘要，不把摘要日期冒充发布时间；发布时间未知就明确未知，不能用抓取时间补齐。
5. 默认不新增生成式新闻摘要或利好/利空评分；本批补齐查找与阅读。媒体报道、公告、行业相关不得混成公司已发生事实。
6. 检索窗口、分页上限、超时/缓存及状态已在[展示契约](../08-backend-api/NEWS-DISPLAY-CONTRACT.md)冻结：7/30/90天、默认30天，每源最多6页，10秒来源预算/12秒总截止，120秒缓存，前端10条一页。

## 必过验收矩阵

- 300199 真实检索：匹配正确主体，有结果时展示真实条目；不能保证任意窗口都有新闻。
- 主源超时、备用有数据：本站仍显示可用新闻和逐源状态，不外跳替代本站内容。
- 所有来源成功且确无匹配 vs 全部请求失败：API及页面呈现不同状态。
- 同名异股、只有数字相撞、行业关键词误关联：不进入公司直接相关新闻。
- 重复转载合并但保留来源；空标题、nan、未来时间、缺发布时间均有测试。
- 首次无缓存、缓存过期、断网/恢复、重启、重复点击、取消和限流：有界结束，不覆盖成功记录，不阻塞K线等模块。
- 未取正文/覆盖不足/单源结果不得静默进入正式辩论；现有决策门禁回归通过。
- 后端提交SHA + 冻结schema + 前端消费者测试 + 实网浏览器截图齐全，才关闭 XI-007。
