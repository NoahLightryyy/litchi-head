###### TD-080 健康统计未区分请求成功与有效业务数据

| 属性 | 值 |
|------|-----|
| **分类** | `可观测性` `severity:moderate` `module:frontend/backend-health` `impact:market-data` |
| **发现日期** | 2026-08-26 |
| **发现人** | AI 审视 |
| **状态** | `🆕 待评估` |
| **本金估算** | ∼4h |
| **日利息** | 空行情可能继续显示为数据源健康，削弱故障判断 |
| **实盘影响** | 用户可能把“接口请求成功”误解为“行情数据可用” |
| **触发场景** | Provider 返回 HTTP 成功但 quote 为 null、K 线或新闻为空 |
| **用户能发现吗** | 页面内容为空时能发现异常，但健康状态不会解释真实原因 |

**描述**：当前 `/api/health/data-source` 统计调用失败，不统计空业务结果。前端已正确适配
该接口，但无法仅凭现有字段判断行情是否真正可用。

**修复方向**：后端增加 `usable_data`、空结果计数和最近有效数据时间；前端分别展示
传输健康与业务数据健康，保持来源事实可追溯。
