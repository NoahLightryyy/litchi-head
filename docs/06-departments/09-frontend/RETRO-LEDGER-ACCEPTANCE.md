## 第一批交付范围

## 现状与复用边界

| 位置 | 已核查能力 | 接入限制 |
|---|---|---|
| `frontend/app/portfolio/page.tsx` | 股票/基金选择、代码/名称、日期、金额输入与本机保存反馈 | 是持仓金额快照，缺成交数量/成交价/事件时区。只复用表单样式，不自动迁移为成交 |
| `frontend/lib/portfolio.ts` | 六位代码、有限金额、日期校验 | 人民币持仓汇总不等于新账本币种设计，不复用成本/金额为成交价格 |

| `frontend/lib/api/client.ts` | JSON客户端和ApiError | 是否需要独立请求头/信封/取消由冻结契约决定；未知错误不展示保存成功 |

## 冻结交接清单

- 提交SHA、Pydantic/OpenAPI、方法/路径、列表排序/分页。
- 记录归属、用户身份来源、用户域与认证边界；前端不得把任填user_id宣称为身份认证。
- 请求幂等键的作用域、冲突码和重复返回语义。
- 发生时间/记录时间、时区、数量和价格精度、币种、可空字段、允许操作类型。
- AI会话引用的可选性及“未核验”状态；不能把旧零分/零置信度当有效研究。
- 校验失败、不可用、权限、超时、写入结果未知时的错误码与重试方式。
- 是否支持修改/作废；未冻结前不提供删除事实或覆盖历史的入口。

## 可执行验收场景（按冻结契约验收）

| 场景 | 期望结果 | 层级 |
|---|---|---|
| 真实手动记录最小事实 | 保存后列表可查，显示原始发生时间与来源标识 | 消费者+浏览器 |
| 可选成交事实留空 | 保持未知；不显示0股、0元或计算收益 | 消费者+浏览器 |
| 非零成交量/价、显式币种 | 无隐式币种转换；非法/非有限/零值按契约阻止 | 消费者+API |
| 巴黎浏览器输入中国交易时间 | 提交和返回的时间表示同一时刻，界面时区可辨 | 消费者+浏览器 |
| 连点保存、超时后同内容重试 | 同一幂等键不产生重复事实；后端返回可确认结果前不称成功 | API+浏览器 |
| 同幂等键不同内容 | 冲突可见，保留草稿，不自动换键掩盖 | 消费者+浏览器 |
| 用户A/B交替查询 | 无缓存串用，无越域回显；身份机制由后端验证 | API+浏览器 |
| 保存失败/断网/重新加载 | 失败可见、输入保留、不自动重复写入；成功记录可重查 | 浏览器 |
| 数据库重启、分页末页、无结果 | 已保存事实仍在；空态与失败、末页分别呈现 | API+浏览器 |
| AI会话不存在/旧研究零默认值 | 原始引用可记录但不冒称研究有效或已采纳 | 消费者+浏览器 |
| 旧复盘涨跌幅/操作标签 | 明示研究后的市场变化和意向标签，不称账户收益或实际成交 | 浏览器 |
| 新接口未部署/格式不符 | 可见兼容或失败状态，不回退写旧标签接口 | 消费者+浏览器 |
