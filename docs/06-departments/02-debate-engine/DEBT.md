### TD-090 决策结果未绑定模型/Prompt/证据版本血缘

| 属性 | 值 |
|------|-----|
| **分类** | `架构设计` `severity:moderate` `module:debate+agents` `impact:效果样本可信度` |
| **发现日期** | 2026-10-01 |
| **发现人** | AI 决策记录审计 |
| **状态** | `🆕 待接线（校验消费者已完成）` |
| **本金估算** | ∼1d；与 TD-068 durable session 接线协同 |
| **日利息** | 新决策继续只能保存观点和聚合分，无法复现当时真实模型、Prompt、配置与证据 |
| **实盘影响** | 旧/新记录可能被错误纳入效果统计，导致置信度校准和真钱扩大依据失真 |
| **触发场景** | 把任一辩论结果与用户操作或后续账户结果配对时 |
| **用户能发现吗** | ❌ 页面可显示完整观点，但缺失版本血缘通常不可见 |

**描述**：`DebateResult` 保留 Agent 原始观点，LLM 层也知道运行模型，但两者没有把
模型、Prompt、配置、代码版本、明确决策时间和带哈希证据引用绑定为同一个不可变决策
快照。UA-03 已新增失败关闭校验器和不可变关联账本，缺失项会明确判为 `ineligible`。

**修复方向**：由服务端生产方在辩论执行当时采集版本血缘，写入 durable
`DebateSessionRecord`，覆盖每个成功 Agent；再开放只读核验/查询 API。不得允许客户端
自行提交 provenance 自证，也不得回填猜测值。正式路由持久化仍由 TD-068 承接。

### TD-069 不完整证据推理缺少统一限制披露与执行隔离

| 属性 | 值 |
|------|-----|
| **分类** | `💻 implementation` `severity:moderate` `module:debate+data` `impact:实盘可信度与运行时成本` |
| **发现日期** | 2026-07-28 |
| **发现人** | AI 真实辩论门禁 |
| **状态** | `🔧 修复中（产品策略已确认）` |
| **本金估算** | ∼1d |
| **日利息** | 数据源降级时若标注丢失，受限推理仍可能被误认为完整结论或进入交易链 |
| **实盘影响** | 用户可能把缺少实时行情、新闻或行业数据的结论当作完整分析，影响真金白银判断 |
| **触发场景** | 东方财富代理失败、新闻解析失败、行业数据源失败，但编排器仍继续运行 |
| **用户能发现吗** | ❌ 当前结果页不显式展示输入完整度；日志可见，但普通用户看不到 |

**描述**：

2026-07-28 对 `000001` 的真实门禁中，实时行情、新闻和行业数据均出现采集错误，
但编排器仍完成 16 次 LLM 调用、耗时约 176 秒并返回成功结果。结果结构完整不等于
输入证据完整，当前既缺少成本短路，也缺少面向用户的数据完整度声明。

**具体问题**：

1. 核心输入没有“必需 / 可选”分级和统一完整度契约；
2. 数据降级不会在开始昂贵 LLM 链前形成明确决策点；
3. `DebateResult` 和前端没有展示缺失来源、数据时间和降级状态；
4. 系统无法区分“允许降级的研究”与“必须拒绝的实盘辅助分析”。

**当前已确认修复方向**：

- 2026-08-26 用户修订：缺源、陈旧、采集失败或不支持时继续研究推理，并在 Prompt、
  结构化结果、摘要和记忆中披露限制；
- 冲突、身份错乱、未来数据或非法 payload 仍在 LLM 前阻断；
- 带限制推理不得进入风控、交易员或 PM 自动执行链；
- 每类数据使用多个真实上游，统一格式后交给业务层；
- 成功空结果与采集失败必须严格区分；
- 2026-07-28 已完成 `src/data/evidence.py` 基础契约和 10 项测试；
- 2026-07-29 已完成 CNINFO 直连三态门禁：真实有数据、明确零公告和失败均可区分，
  AKShare 保留为同一上游的可替换适配器，TD-071 已关闭；
- 2026-07-29 已完成 `DataEvidenceService` 并发汇总和统一 `EvidenceEnvelope`；
- 2026-07-29 已完成东方财富与新浪独立新闻适配器、双源完整性策略和统一聚合 API；
- 2026-07-29 已将新闻 `EvidenceEnvelope` 接入正式辩论图：固定 3 天窗口，任一
  必需新闻上游不完整即返回 503，专项测试确认 LLM 调用数为零；
- 2026-07-29 已将实时行情接入正式辩论图：东方财富与新浪并发直连，成交量统一为
  股；连续竞价采用 10 秒新鲜度、3 秒配对和 0.01 元容差，任一缺源、过期或冲突
  均返回 503，专项测试确认 LLM 调用数为零；
- 2026-07-30 已确认 K 线双时间尺度产品方向：开盘后不等待日 K 收盘；历史
  `FINAL_DAILY`、实时 `LIVE_QUOTE`、已结束 `FINAL_MINUTE` 和今日
  `PROVISIONAL` 动态状态分层进入 AI，动态状态不得冒充收盘形态；
- 2026-07-30 已批准 [ADR-013](../../05-decisions/ADR-013-multi-source-evidence.md)
  的 RAW 双源、版本化公司行动、统一点时复权和完成日线严格对账；
- 2026-07-30 已完成 KR-1A 新浪/腾讯沪深 RAW 旁路对账与北交所失败关闭；该能力
  尚未补交易日历/个股停牌证据和持久化，也未接入正式辩论；
- 分批顺序固定为
  [KR-1～KR-6](../../02-requirements/KLINE_EVIDENCE_IMPLEMENTATION_PLAN.md)，辩论部
  在数据部 KR-1B～3 后承接 KR-4；
- 2026-08-26 新闻/报价基础链已完成降级推理：`EvidenceLimitation` 记录能力、缺失上游、
  来源状态和采集时间，Prompt/结果/摘要/记忆同步携带；54 项定向契约通过；
- TD-069 暂不关闭：K 线与行业证据仍需迁移到统一“限制披露/损坏阻断”契约。

关闭前必须证明缺独立上游/陈旧时仍推理且限制不丢失、风控/交易不执行；RAW 冲突、
复权冲突、身份错乱和未来数据在首个 LLM 前终止。不能因为旧链路已经返回
