### TD-066 JSON/JSONL 存储无生命周期、事务与跨进程安全

| 属性 | 值 |
|------|-----|
| **分类** | `💻 implementation` `severity:moderate` `module:memory` `impact:数据完整性` |
| **发现日期** | 2026-07-28 |
| **发现人** | AI 审视 + 用户容量提问 |
| **状态** | `📋 已确认` |
| **本金估算** | ∼2-3d（含迁移、备份恢复和故障测试） |
| **日利息** | 每增加一条记忆，全文件查询和维护成本继续增长，迁移难度上升 |
| **实盘影响** | 并发写入或进程中断可能导致记忆、复盘和信任记录丢失或损坏，破坏决策复盘 |
| **触发场景** | 多辩论并发、服务重启、磁盘写满、JSON 写入中断、文件达到数千条 |
| **用户能发现吗** | ❌ 通常不能；可能只表现为历史记录少了一条或 Agent 忘记过去 |

**描述**：

`JsonFileStore` 只有进程内 `asyncio.Lock`，JSON 对象采用原地覆写；`RetroStore`
每次读取并重写整个文件。当前没有保留期、原子替换、跨进程锁、事务、索引、
备份恢复或损坏隔离。

**修复方向**：

1. 按 ADR-012 建立 SQL 事实源和 schema migration；
2. 写入必须事务化、幂等并有唯一约束；
3. 增加中断恢复、损坏文件迁移和备份恢复测试；
4. 生命周期默认值由用户确认后落地。
