###### TD-072 L1 分时缺少 20 日同分钟量能基线

| 属性 | 值 |
|------|-----|
| **分类** | `数据完整性` `severity:moderate` `module:data` `impact:live-signal` |
| **发现日期** | 2026-07-29 |
| **发现人** | AI 审视 |
| **状态** | `🔧 修复中` |
| **本金估算** | ∼4h + 20 个交易日自然积累 |
| **日利息** | 无法把当前成交量放进同一时刻的历史季节性背景 |
| **实盘影响** | 若提前显示“放量”，可能把开盘天然高成交误判成异常而误导决策 |
| **触发场景** | 用户查看 Relative Volume、量能突变或突破质量时 |
| **用户能发现吗** | 系统当前明确显示基线不可用；若错误降级则用户难以发现 |

**描述**：
双源一分钟行情和原始累计量已经可用，但项目还没有连续 20 个交易日的同分钟历史
基线。第一版因此只返回 `relative_volume=None` 与明确限制，不用上一分钟或全日均值
冒充行业常用的同期基线。

**修复方向**：
将每日规范分钟曲线写入 Parquet 行情目录，按证券和 `HH:MM` 计算过去 20 个完整
交易日的累计量中位数；数据不足、停牌或缺分钟时继续保持不可用。
