###### TD-073 北交所三家历史转板股缺结构化上市日证据

| 属性 | 值 |
|------|-----|
| **分类** | `数据完整性` `severity:moderate` `module:data` `impact:kline-coverage` |
| **发现日期** | 2026-07-30 |
| **发现人** | AI 实网烟测与双路代码审查 |
| **状态** | `📋 待评估` |
| **本金估算** | ∼4–8h（组合证据模型或逐家公司官方 PDF 解析） |
| **日利息** | 832317/833874/833994 的北交所历史日线无法取得同等级生命周期成功证据 |
| **实盘影响** | 这三家历史转板期间的 K 线完整性会失败关闭，不会误放行 AI |
| **触发场景** | 请求观典防务、泰祥股份、翰博高新在北交所时期的生命周期 |
| **用户能发现吗** | 能；返回“requires composite evidence”，不伪装成证券不存在 |

**描述**：
北交所当前上市清单和新旧代码对照表都不再包含三家已转板沪深市场的历史公司。
市场日历保存其 2020-07-27 的 N 简称/复牌事件和后续摘牌日，北证公告〔2021〕13号
又规定精选层挂牌时间连续计算，但现有单来源生命周期模型不能如实表达这组组合证据。

**修复方向**：
扩展生命周期 provenance 以保存规则公告 + 交易提示的多文档哈希，或逐家公司解析
官方精选层挂牌公告 PDF。完成前保持显式失败；不得硬编码日期或把最早事件直接当
上市日期。

| **实盘影响** | 若提前显示“放量”，可能把开盘天然高成交误判成异常而误导决策 |
| **触发场景** | 用户查看 Relative Volume、量能突变或突破质量时 |

不会进入正式基线；不足20个双源日时继续返回 `relative_volume=None` 和明确限制。

**修复方向**：
继续自然积累20个 `dual_source_verified` 完整日，并对影子回填执行同分钟偏差、
信号排序和误报率验证。验证通过前不晋升单源历史，也不放宽500股实时门槛。
