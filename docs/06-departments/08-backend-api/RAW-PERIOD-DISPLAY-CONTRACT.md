# 周月线备用展示契约（2026-10-07）

既有 GET /api/stocks/{code}/kline-raw-display 增加 days 整数参数，默认90，30–950，越界422。返回 RawDailyDisplay 不变，仍是腾讯单源、不复权、已结束交易日的日线；失败保留原 status/error_code 和空 bars，可手动重试。前端周/月备用请求900天，以实际返回范围为准。

展示层按周一至周日/自然月聚合：首开、最高、最低、末收、成交量求和。不得跨来源/复权口径拼接。标记源为腾讯日线聚合；首尾周期可能不完整，未核验交易日覆盖，不用于替代研究前复权数据。北交所既有 unsupported 不变。
